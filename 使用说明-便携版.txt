PDOS · 结构分析工作台 —— Windows 便携版
=======================================

一、启动
--------
双击  PDOS-Viewer.exe  即可运行，无需安装 Python 或任何依赖。
整个 PDOS-Viewer 文件夹可以随意拷贝到 U 盘 / 其它电脑（x64 Windows 10/11）。

目录结构：

    PDOS-Viewer\
    ├── PDOS-Viewer.exe      ← 双击运行
    ├── _internal\           ← 运行时依赖（Qt / QtWebEngine / matplotlib 等，勿删）
    ├── 3dmol\               ← 3D 结构显示用的 3Dmol.js（勿删）
    ├── assets\              ← 程序图标
    ├── README.md            ← 功能说明
    └── 使用说明-便携版.txt   ← 本文件

二、加载数据
------------
程序不预设数据路径。进入「🧬 晶体结构」页后点击「选择 data 所在路径」，
选中包含下列内容的文件夹：

    <data>\
    ├── CONTCAR 或 POSCAR
    ├── Data-total\      TDOS.dat、FERMI_ENERGY、BAND_CENTER
    ├── Data-element\    PDOS_EIG_UP|DW_<元素>.dat(.bak)、BAND_CENTER_p-dbandcenter_<元素>
    └── Data-atom\       PDOS_EIG_UP|DW_<编号>.dat(.bak)

选中后会自动发现三个子目录并载入 CONTCAR，随后即可在左栏切换各页面：

    🧬 晶体结构          3D 球棍模型、正交投影、六视角、点选原子
    📊 总态密度 TDOS     上下自旋总态密度、带隙/磁性识别、s/p/d 带中心
    🧪 元素 PDOS         每个元素一条曲线（tot 列）+ 带中心
    ⚛️ 原子-轨道-PDOS    指定原子逐轨道曲线，带中心按公式实时计算
    🔬 元素-轨道-PDOS    指定元素逐轨道曲线，带中心按公式实时计算
    🧮 高斯圆滑处理      任选一个数据文件、指定列做一维高斯圆滑并导出

三、导出
--------
- 「保存当前图片」按钮固定在右栏右下角，可把当前曲线图存为
  300 dpi 的 PNG / PDF / SVG / JPEG。
- 「高斯圆滑处理」页可把圆滑后的曲线导出为 .dat 文本
   （两列：Energy(eV) 与 quasi_dos_sigma=<σ>）。

默认保存目录为 exe 所在目录。

四、常见问题
------------
1) 3D 结构区域白屏？
   属于显卡/WebGL 问题。可尝试：
   - 更新显卡驱动；
   - 右键 PDOS-Viewer.exe →「以管理员身份运行」；
   - 若在远程桌面 / 虚拟机中，请开启硬件加速。
   其余 DOS 绘图页面不受影响。

2) 杀毒软件报警？
   这是 PyInstaller 打包的无签名 exe 的常见误报，添加信任即可。

3) 双击没反应？
   请确认 _internal 文件夹与 exe 在同一目录且未被移动。
   若曾把 exe 单独复制出来，请把整个文件夹一起复制。

4) 想改字体 / 主题？
   程序内置明暗主题切换（右上角按钮），界面字体使用系统「微软雅黑」。
